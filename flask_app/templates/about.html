About The Project

AI Powered Brain Tumor Segmentation using Swin-UNet Architecture and BraTS 2021 Dataset.

📖 Project Overview


This system automatically detects and segments brain tumor regions from MRI scans using Swin-UNet Deep Learning Architecture. The application allows MRI upload, prediction generation, ground truth comparison and tumor visualization.

🧬 Dataset Information


Dataset: BraTS 2021

MRI Modalities:
✅ FLAIR
✅ T1
✅ T1ce
✅ T2
