# Brain Tumor Segmentation using Swin-UNet

## Dataset
BraTS 2021

## Deep Learning Model
Swin-UNet

## Frameworks
- Python
- PyTorch
- MONAI
- Flask

## Features

- Upload MRI Scans
- Brain Tumor Segmentation
- Whole Tumor (WT) Visualization
- Tumor Core (TC) Visualization
- Enhancing Tumor (ET) Visualization
- Dice Score Evaluation
- IoU Evaluation
- Prediction History
- Result Download
